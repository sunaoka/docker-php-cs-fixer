# PHP Coding Standards Fixer (PHP CS Fixer) Docker image

## Usage

```bash
docker run --rm -v $(pwd):/app -w /app ghcr.io/sunaoka/docker-php-cs-fixer:latest --diff -v
# or
docker run --rm -v $(pwd):/app -w /app sunaoka/php-cs-fixer:latest --diff -v
```
